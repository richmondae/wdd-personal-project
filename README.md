# Richmond Akpama — Portfolio

A warm, responsive portfolio built with plain HTML, CSS, and JavaScript.

## Run locally

Open `index.html` in a browser or use VS Code Live Server. No build step is required.

## Portfolio content

- Experience, education, technical skills, professional strengths, and certifications are drawn from Richmond's 2026 résumé.
- The portfolio portrait is stored locally as `richmond-portrait.jpeg`.
- EduBridge and Go Business are featured as frontend prototypes. Their repositories are private, so the project cards invite visitors to ask about the code.
- Bellefood & Supermarket is featured without unverified implementation claims because no matching repository was available.

## Tech

- HTML5
- CSS3, responsive layout, custom illustrations, reduced-motion support
- Vanilla JavaScript
